# 迭代计划 V3.0 —— 第二轮对标 · 新维度差距 · 实施清单

> 基线:Sable UI v2.0.0(@ `98ae8ae`,414 测试)。V2.0 已收口 G1(SVG)/G2(树面板)/
> G6(效果栈面板)/G10(模糊冒烟)/G11(撤销光标)。本轮换**新维度**再对标:
> 文本引擎、颜色管理、多窗口、脚本自动化、无障碍深化、程序化编辑。

---

## 1. 第二轮对标(新维度)

| 库 | 为什么再看 | 本轮新借鉴面 |
|---|---|---|
| **Inkscape 1.x** | 开源矢量编辑器(与 Sable 应用层同生态位) | 画布真文本(Text 工具+字形轮廓化)、SVG filter 全集、命令行批处理 |
| **Figma(架构公开资料)** | 协作设计标杆 | 文档变更流、插件沙盒、文本排版引擎、颜色(原生色域) |
| **Qt 6 QTextDocument** | 富文本引擎参照 | 文本布局/光标/选区模型、stylesheet 主题 |
| **Blender 4.x** | 创作软件自动化标杆 | Python 脚本 API 形态(operator/属性注册)、内置性能遥测 |
| **Makepad** | Rust GPU UI 先行者 | 着色器驱动的 UI 效果(与 E1 方向互证)、live reload |
