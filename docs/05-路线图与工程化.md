## 2. 工程化规约

### 2.1 代码组织纪律(依赖方向,2026-10 实况)

```
lumina-widgets ─┬─▶ lumina-canvas ──▶ lumina-paint ──▶ lumina-core ──▶ (kurbo/slotmap/serde)
lumina-dock ────┘        ▲                                        ▲
lumina-video ────────────┘(2026-10 决策:video 只依赖 core,不经过 canvas)
应用层 my-app ──▶ lumina 门面   # 应用只依赖门面,不许跨层深依赖
```

> **2026-10 偏差说明**:原金字塔画的是 `video → canvas → core`;实际 lumina-video **只依赖 lumina-core**(时间轴模型不需要场景图,时间轴视图在 widgets)。 Cargo.toml 注释已登记理由。

- **禁止**在 `lumina-*` 里出现业务名词("剪映""贴纸""CutForge"等业务词留在应用层,AGENTS.md §3.5)
- **禁止**绕过 Command 直接改 Scene(clippy 自定义 lint 或 review 把关;AGENTS.md §3.1)
- **必须**每个组件配一个 `examples/` 独立可跑示例(仿 gpui-component 的 story)
- **core 零 UI 依赖**:CI 用 `--no-default-features` 单独编译把关(paint 的 gpu/cpu 双 feature 均不开时也不依赖 gpui —— 已按此构建)

// 属性测试示例(已实现版,v0.1 实际策略更完整:9 类操作 + id 注册表存活过滤)
proptest! {
    #![proptest_config(ProptestConfig::with_cases(256))]
    #[test]
    fn random_command_sequence_full_undo_restores_snapshot(
        ops in proptest::collection::vec(any_op(), 1..50),
    ) {
        let (mut scene, ..) = demo_scene();
        let snapshot = scene.clone();
        let mut history = History::new();
        for op in &ops { /* exec 到 history+scene */ }
        while history.can_undo() { history.undo(&mut scene); }
        prop_assert_eq!(scene, snapshot);   // 撤销 N 步必须精确还原(结构化相等)
    }
}

### 2.4 Windows 打包发布

```toml
# Cargo.toml(release 优化;本仓库已就位)
[profile.release]
lto = "thin"
strip = "debuginfo"   # v0.1 实况:先剥调试信息;正式发行可换 strip = true
```

> 本仓库另有 `[profile.dev] debug = 1`(借鉴 VellumBench:dev 全量调试信息是 target 膨胀主力;本机 C 盘只剩 ~1GB,cargo 产物全部落 D 盘)。

| 事项 | 方案 |
|---|---|
| 安装包 | **WiX**(`cargo-wix`)或 NSIS;体积敏感用 7z 自解压 |
| 图标/资源 | `embed-resource` 嵌入 .rc(exe 图标、版本信息、DPI 感知声明) |
| DPI 感知 | manifest 声明 `PerMonitorV2`(GPUI/winit 处理缩放) |
| 自动更新 | 自建:GitHub Releases + 差分;或接 `tauri-updater` 思路自实现 |
| 崩溃上报 | `minidumper` + `crash-handling`(Zed 同款方案),符号用 `symbolic` |
| ffmpeg 分发 | 随包带 DLL(注意 LGPL:动态链接 + 提供源码声明);或 GStreamer 运行时装机检测(TD-11) |
| 代码签名 | 正式发行需 EV 证书(否则 SmartScreen 拦截),预算约 2000-4000 元/年 |

## 5. 关键设计附录

### 5.1 工程文件格式(.lumi)

```
文件 = zip 容器
├── manifest.msgpack     # 版本号、画布尺寸、时间轴元数据
├── document.msgpack     # 场景图全量(serde + rmp-serde;Scene 已随时可序列化 ✅)
├── timeline.msgpack     # 轨道/clip/关键帧
├── history.msgpack      # (可选)撤销栈,实现"关闭重开还能撤销"
└── assets/              # 内嵌素材(小文件直接内嵌;大文件存引用路径+哈希)
    ├── fonts/
    └── thumbnails/
```

- 版本迁移:`manifest.version` + serde `#[serde(default)]` 前向兼容(TD-05:第一个字节就定规范)
- 大文件:素材按内容哈希寻址(CAS),多工程共享素材
- 写入纪律:**只有一条路** —— `lumina_core::persistence::atomic_write`(tmp + fsync + rename,已实现并测试;分册六 §1.2)

### 5.2 与 Adobe/剪映生态互通
