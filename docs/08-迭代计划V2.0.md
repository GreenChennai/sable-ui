# 迭代计划 V2.0 —— 同类库对标 · 差距分析 · 实施清单

> 基线:Sable UI v1.0.0(@ `67b8512`,389 测试)。方法:横向对标同类 UI 库(不限语言)
> 的**能力面**,按"创作工具前端"这一生态位找差距;每项差距标注对标来源与验收方式。
> 执行约束:V2.0 全程主会话实现(子 Agent 配额周期性锁死),因此按"小步、可测、独立合入"排序。

---

## 1. 对标库与生态位

| 库 | 语言 | 为什么对标 | 借鉴面 |
|---|---|---|---|
| **Qt 6**(Widgets/Quick) | C++ | 桌面创作工具的事实标准底座(docking/属性面板/QUndoCommand) | 撤销框架、模型/视图、富文本、无障碍、国际化 |
| **egui 0.3x** | Rust | 同语言最成熟即时模式库 | 布局习惯、热重载体验、无障碍(AccessKit 已内置) |
| **Flutter 3.x** | Dart | 渲染管线与动效体系(Impeller)、合成器 | 效果管线分层、动画组合、无障碍桥 |
| **SwiftUI / AppKit** | Swift | 平台级声明式 UI + IME/无障碍标杆 | 状态驱动动画、树视图(Navigator)、文本编辑 |
| **Dear ImGui** | C++ | 工具型 UI 的密度与性能上限 | DockBuilder、表格/树虚拟化 |
| **Konva / Fabric.js** | JS | **画布编辑器**场景图(最贴近本库 L3 生态位) | 事件命中、变换缓存、SVG 序列化、图层混合 |
| **Graphite / Excalidraw** | Rust/TS | 开源矢量编辑器前端 | 场景文档模型、协作指针 |

## 3. V2.0 主题与任务(按"主会话可独立小步合入"编排)

### T1 · SVG 互通(G1,P0)——本周期首个合入项
| # | 任务 | 验收 |
|---|---|---|
| 1.1 | **SVG 导出**:`sable-foundation::svg::export(scene) -> String`——子树→`<path transform fill stroke/>`,渐变→`<linearGradient/>`,混合模式→`style="mix-blend-mode"` | 导出串可被 `usvg` 解析;单测含渐变/描边/组 |
| 1.2 | **SVG 导入**:`svg::import(svg) -> Scene`(usvg 解析→路径节点;组→Group;文本降级占位) | 导入→导出 roundtrip 形状集合一致(容差断言);拒绝超大文件(分册六 §1.3) |
| 1.3 | 门禁:两测试进 CI;大小上限可配(默认 10MB) | fuzz 前置:解析全 Result 无 panic |

### T2 · 树形图层面板(G2,P0)
| # | 任务 | 验收 |
|---|---|---|
| 2.1 | `LayerTreePanel`:层级缩进/展开折叠/选中透传(复用 LayerPanel 回调语义)+ FLIP 让位 | 5 层嵌套渲染正确;折叠状态可撤销?否——视图态不入撤销栈(doc 注明) |
| 2.2 | 拖拽重排挂 `Reparent`(命令已备) | 拖 B→组内一次撤销还原 |

### T3 · 工程加固(G10,P1)
