## 2. 核心技术决策(08 号计划定案)

**毛玻璃分两层,两条路:**

```
窗口级毛玻璃(整窗)     →  Windows DWM 系统材质(Mica/Acrylic)——E3
                            一次 API 调用;GPU 开销零(DWM 合成器承担)
面板级毛玻璃(库内控件)   →  自研 Dual Kawase 模糊管线(WGSL)——E1/E2
                            一条渲染管线;这是 UI 库的真正资产
```

**模糊算法 = Dual Kawase**(ARM SIGGRAPH 2015):降采样链 + 4-tap Kawase 核 + 升采样重建。
比优化高斯快 1.5~3 倍,大半径优势更大,运动稳定无闪烁。
**不用 vello 内置 blur filter 做 UI 毛玻璃**:backdrop blur 需要采样"面板背后的已渲染内容"
(跨 pass 操作),vello filter 只留给内容级效果。

## 4. E12 降级矩阵(v0.2 实况)

| 能力 | Full(gpu feature) | Reduced(cpu-only) | Off(env 强制) |
|---|---|---|---|
| blur(毛玻璃/阴影) | 全质量 | 可用,质量减半(box 半径减半/ Kawase 减 pass,消费方按 Level 定) | 关:纯色+描边替代 |
| blend(混合模式) | 全 16 种 | 全 16 种(vello_cpu 原生混合层,无损失) | 关:一律 Normal |
| grain(蓝噪点) | 开 | 关(防色带交给渐变插值) | 关 |

## 5. 性能军规(防"效果很炫、帧率很惨")

1. **静止零成本**:背景不变 → 模糊/阴影结果整帧复用(E2/E4 与脏矩形体系同生死)
2. **模糊面积上限**:同屏毛玻璃总面积 ≤ 屏幕 40%,超出自动降 pass 数(调度器强制)
3. **半径换采样**:radius > 48 自动加深降采样链(像素更少,视觉等价)
4. **效果栈求值合并**:E6 多滤镜矩阵相乘成一次 pass,禁止 N 滤镜 N 次全屏 pass
