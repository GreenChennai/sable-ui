## 1. 总纪律(动工前钉死,全程有效)

1. **ARL-1.0(阻断级)**:apps/desktop 只**消费**内核契约——`cutforge-schema` 类型 +
   `/rpc` 工具面 + GET 白名单(/session /ui-fields /events /media /catalogs);
   **零语义复制**:吸附/时长推导/重叠判定/变速换算等时间线语义一律不落壳
   (壳=投影+意图提交,真相在内核 Engine)。不修改 `CORE-FILES` 36 文件任何一行。
2. **ACL-1.0(VellumBench 侧)**:语义/数值事实对齐,禁止复制源码、禁止逐行翻译;
   实现者以规格文档与 tokens JSON 为输入。
3. **磁盘纪律(本机现实)**:C 盘 0 可用,D 盘 ~22G。构建一律落 D 盘 target;
   桌面壳构建用 `CARGO_PROFILE_DEV_DEBUG=0`(gpui 全量 debug 工件 ~5G+);
   每里程碑收口清 `target/debug/incremental` 与废弃 crate 工件。
4. **门禁**:两侧仓库各自 fmt → clippy -D warnings → test 全绿才提交;
   桌面壳每阶段过真机冒烟(开窗/连接/操作),结果如实记录。

## 2. CutForge 桌面化(apps/desktop,网页壳 → 桌面软件)

架构:**内核不动,壳换皮**。`cutforge-cli serve` 继续当后端(桌面壳负责拉起它),
桌面壳 = sable-dock 三段式工作台 + /rpc 客户端 + 视图投影。

| 阶段 | 交付 | 验收 |
|---|---|---|
| **C-FE1 骨架** | apps/desktop bin(workspace member,依赖 `sable` path + `cutforge-schema` + `ureq`);GPUI 开窗 + sable-dock 三段式(左媒体库/右检查器/下时间轴 + 中预览);内核子进程拉起(serve --root --port --token,退出随壳);`/rpc` 统一客户端(Envelope/超时/只读重试,Bearer) | **ADR-0039 冒烟上半:开窗 + 连接内核 + project_get 拿到工程标题** |
| **C-FE2 时间轴只读** | `timeline_get` JSON → sable-video `Timeline` 视图投影(轨道/clip/时长只读映射,**零推导**)→ `TimelineView` 渲染;播放头 + 缩放;选中 clip 高亮 | **冒烟下半:时间轴渲染出真实工程轨道/片段**;投影无 ms 算术(审计) |
| **C-FE3 编辑闭环** | GET `/ui-fields` 驱动检查器分组(editable 组→NumberField/开关;readonly 组→只读展示);字段提交 `clip_update`(ClipPatch 分组)/`clip_trim`/`clip_split_all`/`clip_copy`/`clip_paste_at`/`track_update`/undo/redo;`GET /events` 长轮询线程 → rev 变化 → 重投影(壳不缓存真相) | 改 startMs/volume/speed 落盘可撤销;Web 壳与桌面壳同开互见改动(同一内核) |
| **C-FE4 预览与导出** | `render_frame` 单帧 → PNG → gpui image(播放头变化即刷新,渲染豁免超时);`render_run` 导出 + `render_progress` 轮询进度条;媒体库面板(`media_browse` + `/media` 缩略图) | 预览帧与 Web 壳一致(同一工具);导出全程壳不死锁 |
| **C-FE5 收口** | `start-desktop.cmd`(选工程→拉内核→开壳);布局序列化(sable-dock);README + ADR(壳/内核边界,承接 00 号 §4.3 风险) | 门禁三连绿 + 全流程冒烟:新建→导入(经 Web 壳兼容路径)→编辑→预览→导出 |

**明确不做(诚实边界)**:连续实时预览(内核 render_frame 100ms 量化,M6 渲染后端议程);
波形/示波器自绘(C-FE4 之后的波次);进程内内核直连(先 RPC 后评估);
关键帧曲线编辑器(内核 readonly,候 FE 批次)。

## 4. 与 Sable 侧的联动缺口(CutForge 桌面化会反哺的库项)

1. sable-dock 布局序列化的实际宿主验证(C-FE5 首个真实验收场);
2. sable-widgets TimelineView 大工程量(1k clips)表现数据(内核 e2e 工程实测);
3. 预览纹理通道:render_frame PNG → gpui image 已可走通,GPUI 纹理直传留 M6;
4. 键位:桌面壳快捷键以 cutforge 45 条注册表为单源,Sable keymap 只做绑定层(00 号 §4.7)。
